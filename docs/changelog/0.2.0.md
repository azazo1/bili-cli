# bilibili-cli v0.2.0

Date: 2026-09-27

本版本新增私信, 本地订阅和直播录制, 并把用户引用扩展到用户名和空间链接. 现有 `config.toml` 会自动迁移到 version 4.

## Highlights

- 新增 `bili msg` 查看, 发送, 标已读和删除一对一私信; `--json` 会展开图片链接和视频卡片, `--before` 可翻更早的消息.
- 新增 `bili watch` 在本地轮询 UP 视频, 直播, 动态, 视频数据和搜索, 支持 webhook 与 exec 通知.
- 新增 `bili live download` 可中断的直播录制, 支持中文画质名, 时长和体积上限.
- 用户命令接受用户名, 空间链接和 b23 短链, 并可用 `bili user lists` 浏览合集与系列.
- 新增 `safety.non_destructive`, 允许点赞, 投币, 关注和发私信, 但拒绝取关与删除.

## Upgrade Notes

1. 升级前可备份 `~/.config/bilibili-cli/config.toml` 和 `auth.json`.
2. 替换 `bili` 二进制后首次运行会把配置迁移到 version 4, 并写入默认关闭的 `safety.non_destructive`.
3. 用 `bili --version` 确认输出为 `v0.2.0`. `bili video watch` 仍是稍后再看, 本地订阅使用 `bili watch`.

## Features

- 私信: `bili msg` 列出会话, 查看未读, 展开单条, 发送纯文本, 标已读和删除会话; `show` 默认不标已读.
- 订阅: `bili watch add/list/check/run` 把规则写到 `watch.json`, 全程只读.
- 直播: 支持 FLV 和 HLS, 默认原画, `Ctrl-C` 保留已录文件.
- 用户: 合集和系列统一入口, 目录可翻页.
- 安全: 写操作拆成普通写入和破坏性写入, `read_only` 优先于 `non_destructive`.

## Bug Fixes

- 直播: 第一次中断会收尾并尽量修复文件时长; 体积单位解析更稳定.
- 下载: 并行分片下载时进度随已写入字节更新.
- 订阅: Windows 上 exec 通知改用 `cmd /C`, 不再依赖 `/bin/sh`.
- 用户: 合集和系列目录能加载完整后续页.
